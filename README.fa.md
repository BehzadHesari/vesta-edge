# Vesta Edge

**یک داک شناور و شیشه‌ای برای لبه‌ی صفحه‌ی نمایش.**<br>
داک را به هر لبه‌ای بکشید، همان‌جا می‌چسبد: ایموجی، تاریخچه‌ی کلیپ‌بورد با حفظ استایل، رنگ، یادداشت، برنامه‌های شما و چند ابزار کاربردی، با یک حرکت موس.

## امکانات

- **چسباندن به هر لبه:** داک را با بدنه‌اش بکشید و رها کنید؛ به نزدیک‌ترین لبه (چپ، راست، بالا یا پایین) می‌چسبد و به‌صورت ستون یا ردیف درمی‌آید. اگر به لبه‌ی بالا یا پایین نزدیک شوید، خودکار افقی می‌شود.
- **تاریخچه‌ی کلیپ‌بورد با پیست با استایل:** متنی که کپی می‌کنید، ضخیم، مورب، رنگی، لینک‌دار و لیست‌دار می‌ماند. روی هر آیتم دو دکمه هست: **Aa** با استایل پیست می‌کند و **T** متن ساده پیست می‌کند. آیتم‌های سنجاق‌شده بعد از راه‌اندازی مجدد هم می‌مانند. تصاویر هم ذخیره می‌شوند.
- **ایموجی** با جست‌وجو، دسته‌بندی و موارد اخیر. با کلیک، ایموجی در برنامه‌ای که قبلاً استفاده می‌کردید نوشته می‌شود.
- **انتخاب رنگ:** از هر نقطه‌ی صفحه رنگ بگیرید و کد HEX، RGB یا HSL را کپی کنید. پالت و رنگ‌های اخیر هم نگه داشته می‌شوند.
- **یادداشت** در چند برگه، با ذخیره‌ی خودکار. **قطعه‌متن‌ها** را با یک کلیک پیست کنید.
- **ابزارها:** ماشین‌حساب، تبدیل واحد، تولیدکننده‌ی رمز، تایمر، کرنومتر، ساعت جهانی، ابزار متن (حروف بزرگ و کوچک، Slug، Base64، شمارش کلمه و…)، کلیدهای رسانه، بیدار نگه داشتن سیستم، قفل، خاموش کردن صفحه و **تقویم شمسی**.
- **برنامه‌ها و پوشه‌های شما:** آن‌ها را به داک سنجاق کنید، یا فایلی را روی داک رها کنید.
- **تم‌ها:** ۱۵ تم رنگی به‌علاوه‌ی رنگ دلخواه. گزینه‌ی ظاهر: پیروی از تم، پیروی از ویندوز، یا اجبار به حالت تاریک یا روشن.
- **به‌روزرسانی داخلی:** هر روز نسخه‌ی جدید را از GitHub بررسی می‌کند و در صورت تأیید شما، نصب‌کننده‌ی آن را دانلود و اجرا می‌کند.
- در **System Tray** اجرا می‌شود، می‌تواند همراه ویندوز راه بیفتد، و فقط یک نسخه از آن همزمان اجرا می‌شود.

## نصب

۱. **`VestaEdge-Setup.exe`** را از [آخرین نسخه](https://github.com/BehzadHesari/vesta-edge/releases/latest) دانلود کنید.
۲. آن را اجرا کنید. برنامه فقط برای کاربر فعلی نصب می‌شود و به دسترسی مدیر نیاز ندارد.
۳. گزینه‌های دلخواه (اجرا همراه ویندوز، ورودی راست‌کلیک) را انتخاب و نصب را تمام کنید.

فایل‌های دیگر صفحه‌ی انتشار:

| فایل | توضیح |
|---|---|
| `VestaEdge-Setup.exe` | نصب‌کننده (پیشنهادی) |
| `VestaEdge-portable.exe` | یک فایل، بدون نصب |
| `VestaEdge-windows-x64.zip` | پوشه‌ی برنامه به‌همراه همین راهنما |

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ (۶۴ بیتی). بسته‌ی WebView2 در ویندوز ۱۰ و ۱۱ از قبل وجود دارد.

## راهنمای استفاده

- **باز کردن:** نشانگر را روی رِیل باریک لبه ببرید، یا روی آن کلیک کنید.
- **جابه‌جایی:** روی بدنه‌ی داک (جایی که آیکونی نیست) فشار دهید و بکشید. هرجا رها کنید، به نزدیک‌ترین لبه می‌چسبد.
- **پیست با استایل:** کلیپ‌بورد را باز کنید، روی یک آیتم ببرید و **Aa** (با استایل) یا **T** (متن ساده) را بزنید. کلیک روی خود آیتم هم با استایل پیست می‌کند.
- **افزودن برنامه:** تنظیمات ← ابزارک‌ها ← *افزودن برنامه*، یا یک فایل را روی داک بکشید.
- **راست‌کلیک روی فایل یا پوشه** ← *افزودن به Vesta Edge* (اگر این گزینه را فعال کرده باشید).
- **تنظیمات:** آیکون چرخ‌دنده‌ی انتهای داک. تم، ظاهر، رفتار پیست، نمایشگر، اجرا همراه ویندوز و به‌روزرسانی.
- **خروج:** تنظیمات ← *خروج*، یا از آیکون سینی سیستم.

## محل ذخیره‌ی اطلاعات

همه‌چیز روی همین رایانه و در `%APPDATA%\VestaEdge` ذخیره می‌شود: تنظیمات، یادداشت‌ها، تصاویر سنجاق‌شده‌ی کلیپ‌بورد، موقعیت داک (`dock.json`) و یک فایل گزارش کوچک. چیزی به جای دیگری فرستاده نمی‌شود، جز درخواست بررسی آخرین نسخه از GitHub.

## حذف برنامه

تنظیمات ویندوز ← Apps ← *Vesta Edge* ← Uninstall. پوشه‌ی تنظیمات حذف نمی‌شود؛ اگر می‌خواهید آن را هم پاک کنید، پوشه‌ی `%APPDATA%\VestaEdge` را حذف کنید.

## ساخت از روی سورس

```bash
git clone https://github.com/BehzadHesari/vesta-edge
cd vesta-edge
cargo build --release
```

نصب‌کننده‌ی ویندوز با [Inno Setup 6](https://jrsoftware.org/isinfo.php) ساخته می‌شود:

```bash
iscc /DAppVersion=1.0.0 installer/vesta-edge.iss
```

برنامه با Rust نوشته شده و از tao و wry (با WebView2 در ویندوز) استفاده می‌کند. کل رابط کاربری در یک فایل است: [`src/ui.html`](src/ui.html).

## محدودیت‌ها

- **فعلاً فقط ویندوز.** داک، چسبیدن به لبه‌ها و پیست با استایل برای ویندوز پیاده شده‌اند. نسخه‌ی macOS و لینوکس در این انتشار نیست.
- پیست با استایل فقط قالب‌هایی را منتقل می‌کند که برنامه‌ی مقصد می‌فهمد (HTML و RTF). بعضی برنامه‌ها فقط متن ساده می‌پذیرند.
- پیست به برنامه‌ای می‌رود که قبل از باز کردن داک در آن کار می‌کردید.
